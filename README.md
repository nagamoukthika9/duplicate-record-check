# Duplicate Record Check

## Project Overview
This project focuses on identifying duplicate records in a Superstore dataset using Microsoft Excel and Python Pandas.

## Tools Used
- Microsoft Excel
- Python
- Google Colab
- Pandas

## Tasks Performed
- Checked for exact duplicate records.
- Identified duplicates excluding the Row ID column.
- Checked duplicate Order ID and Product ID combinations.
- Created a cleaned dataset.
- Prepared a duplicate report.

## Results
No duplicate records were identified in the checks performed.

## Project Deliverables
- Original dataset
- Cleaned dataset (CSV and Excel)
- Duplicate report
- Python notebook

## Conclusion
The dataset was checked for duplicate records using Excel and Python Pandas. The cleaned dataset and duplicate report were prepared successfully.
